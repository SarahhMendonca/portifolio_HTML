# 🌐 Portfólio Pessoal - Sarah Mendonça

Este é o repositório do meu portfólio pessoal, desenvolvido como atividade prática durante o curso **Técnico em Desenvolvimento de Sistemas** na escola **SENAI A. Jacob Lafer**. 

O projeto foi construído para consolidar os conceitos fundamentais de estruturação web, semântica em HTML5 e criação de formulários e tabelas.

---

## 📌 Sobre o Projeto

A página consiste em um site de apresentação pessoal e profissional contendo:
* **Cabeçalho e Apresentação:** Informações principais e links de navegação rápida.
* **Sobre Mim:** Resumo da trajetória acadêmica, objetivos e foto de perfil.
* **Habilidades:** Lista com os principais conhecimentos adquiridos no curso (HTML, PHP, Banco de Dados, ABNT).
* **Projetos:** Tabela organizada destacando projetos práticos com links para os repositórios no GitHub.
* **Contato:** Formulário interativo para envio de mensagens, propostas e oportunidades de trabalho.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página (`<header>`, `<footer>`, `<form>`, `<table>`, `<address>`).
* **CSS Inline:** Estilização básica de cores de fundo e texto utilizando valores HSL e RGB.
